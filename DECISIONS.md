# DECISIONS

Решения, принятые без вопросов к заказчику.

1. **Стек**: Next 16.4.2 (`output: 'export'` проверен), React 19, Tailwind v4 (`@theme` в `globals.css`), Motion, GSAP+ScrollTrigger, Lenis, lucide-react. Валидация формы — `zod` напрямую (без react-hook-form: `@hookform/resolvers@6` конфликтует по peer-зависимостям, а форма простая).
2. **Telegram**: в ТЗ `t.me/9268778833`, на старом сайте `t.me/+79808887103`. Используем ТЗ; значение живёт в `content/site.ts`.
3. **Режим работы**: 10–20 vs 10–21 → `Ежедневно [10:00–20:00]` с видимой заглушкой.
4. **Цитаты отзывов**: в ТЗ их нет → везде заглушки `[цитата … — подобрать]`. Реальные тексты с Яндекс Карт, найденные в коде старого сайта, **не** выводятся — решение за Вами/заказчиком.
5. **Чего нет в ТЗ — не используем**: email со старого сайта, «стандарты BMW Group», «лицензированное оборудование», слова «официальный/дилерский/авторизованный».
6. **Фото**: Unsplash/Pexels недоступны из среды сборки → весь визуал нарисован SVG/CSS (силуэт, сетка, свет, зерно). Слоты под реальные фото клиента — заглушки `[фото — …]`. `content/credits.ts` пуст до добавления стоков.
7. **Шрифты**: `next/font/google` (скачиваются на билде, раздаются с нашего домена; Tektur, IBM Plex Sans/Mono, кириллица).
8. **Силуэт**: собственный обобщённый профиль седана/хэтча, без решётки и фирменных линий. Цвета: `--color-volt #3D8BFF` светлее и насыщеннее BMW-синего `#1C69D4`.
9. **Pin-сцена «Как работаем»**: только ≥768px и без `prefers-reduced-motion`; иначе вертикальный список, стрелка спидометра реагирует на скролл.
10. **Форма**: Telegram не принимает предзаполненный текст в личный чат → копируем заявку в буфер и открываем чат; WhatsApp — заглушка до номера.
11. **Мобильное меню/панель**: бургер на весь экран; нижняя панель «Позвонить · Telegram · Записаться» (<768px).

## Итерация 2 (схема, «Как найти», оптимизация)
12. **Схема автомобиля** — собственный чертёж (`components/art/carGeometry.ts` + `CarBlueprint.tsx`): кузов с градиентами, стёкла, стойки, ручки, фары, колёса со спицами и тормозными дисками, салон и «рентген» агрегатов (двигатель, КПП, подвеска, рулевое, тормоза, электрика). Используется в hero (прорисовка + луч + проявление «рентгена» при скролле + параллакс мыши), в «Что беспокоит?» (подсветка выбранного узла, выносные линии) и на `/series/[slug]`.
13. **«Как найти»** — условная схема двора с анимированным маршрутом и маркером машины, шаги-вкладки с автопереключением; реальная схема — заглушка `[реальная схема двора — от клиента]`.
14. **Оптимизация**: Lenis/GSAP подгружаются после первой отрисовки; hero-текст анимируется на CSS (виден без ожидания JS); шум — PNG вместо SVG-фильтра; курсор и модалка — `next/dynamic`; Tektur — вариативный шрифт, моно без preload. Lighthouse (эмуляция мобильного, локальный сервер без сжатия): Performance ≈72, Accessibility 100, Best Practices 100; реальный LCP ≈0,7 с.
15. **Контраст**: основные кнопки — тёмный текст на `volt` (белый давал 3.3:1).

## Итерация 3 — плавность (замер `npm run perf` / `scripts/perf.mjs`, Chromium без GPU, CPU ×4)
| Сценарий | до | после |
|---|---|---|
| hero, покой (загрузка потока) | 75% | 10% |
| hero, движение мыши | 31,6 fps | 59,5 fps |
| прокрутка всей страницы (десктоп) | 35 fps | 45–49 fps |
| прокрутка всей страницы (мобильный 390) | — | 53 fps |

Что сделано, без изменения вида:
- вращение спиц вынесено в отдельный слой на композиторе (раньше перерисовывался весь SVG каждый кадр);
- луч света и его `mask`/`drop-shadow` убираются из DOM после проигрывания; штриховой режим линий снимается после прорисовки;
- убраны blend-режимы (`overlay` у зерна, `screen` у света фар), бесконечный пульс узла с `drop-shadow`;
- маска ленты «Как работаем» заменена неподвижными градиентными оверлеями; свечение карточек — через opacity;
- `backdrop-blur` шапки/нижней панели: меньший радиус и собственный слой; курсор «засыпает» в покое;
- параллакс и «рентген» hero: `will-change`, проявление по времени, а не покадрово от скролла;
- бесконечные анимации (спицы, marquee, пульс хотспотов) ставятся на паузу вне экрана (`usePauseOffscreen`);
- `Reveal`: на крупных блоках без blur, `filter` снимается после проигрывания.
Оставшаяся нагрузка при скролле — растеризация SVG-схем в программном рендерере; на устройствах с GPU она заметно ниже.

## Итерация 4 — акцент на BMW (решение заказчика работы, заменяет часть запретов А10)
16. **Машина в BMW-пропорциях**: короткий передний свес, длинный капот, кабина сдвинута назад, «акулий» нос, излом Хофмайстера на заднем боковом стекле, «жабры» на крыле, характерная линия по борту, L-образный задний фонарь, двойные спицы, два выхлопа, задний привод (кардан → дифференциал). Вид спереди (`CarFront`) — двойные «ноздри» и «ангельские глазки».
17. **Не используется**: эмблема-логотип BMW (товарный знак), фирменные шрифты, цвета M-полос. Дисклеймер «не является официальным дилером» в футере остаётся; слова «официальный/дилерский/авторизованный» не используются.
18. **Текстовый акцент**: блок «BMW — наша работа с 2000 года» с чипами всех серий (ссылки на `/series/*`), «BMW» выделено цветом в hero, заголовках серий и панели ТО, «Серия BMW» в форме и тексте заявки.
